== v0.2 — RS256 sign + verify

*Status: done in scaffold; awaiting CI / packaging.* Implementation
landed via option (a) (hand-rolled on top of `std.crypto.ff`, no
dependencies). Total RS256 code surface ≈ 250 LoC.

=== Implementation choice

Option (a) won. Zig 0.15.2's `std.crypto.ff` provides `Modulus(bits)` with
Montgomery `powWithEncodedExponent` (constant-time, secret-exponent path) +
`powWithEncodedPublicExponent` (faster, public-exponent path) — the hard
part of RSA is already there as a finite-field primitive. What we added on
top:

* PKCS#8 unencrypted PEM parser (standard-base64 decode + ASN.1 DER walker;
  rejects PKCS#1 PEMs at the boundary so the consumer is forced to pass
  `openssl pkcs8 -topk8` output).
* PKCS#1 v1.5 padding builder for SHA-256 (RFC 8017 §9.2, fixed-shape).
* `hpm_crypto_rs256_sign` wired to `pow` (secret exponent).
* `hpm_crypto_rs256_verify` wired to `powPublic` (public exponent), takes
  raw `(n, e)` bytes rather than a PEM (verifier-side callers already
  have a parsed key from upstream JWKS / SPKI discovery).

Supported key size: **RSA-2048 only** — `Modulus(bits)` is comptime, so
other sizes (3072 / 4096) need their own instantiation. Tracked for
v0.2.1.

=== v0.2 deliverables

* [x] Standard-base64 (RFC 4648 §4) lenient decoder for PEM bodies
* [x] ASN.1 DER walker (SEQUENCE / INTEGER / OCTET STRING; short + long-form length)
* [x] PKCS#8 unencrypted PEM parser (extracts `n`, `e`, `d`)
* [x] PKCS#1 v1.5 padding builder for SHA-256
* [x] `hpm_crypto_rs256_sign` (RSA-2048)
* [x] `hpm_crypto_rs256_verify` (RSA-2048; takes raw `n`, `e`)
* [x] KAT test against an OpenSSL-generated signature (`echo -n "hello world" |
  openssl dgst -sha256 -sign test.pem`)
* [x] Round-trip + deterministic-output + altered-message + wrong-sig-length
  + malformed-PEM + size-query test coverage
* [x] Idris2 wrapper updates: `rs256Sign` no longer carries a "not
  implemented" warning; `rs256Verify` added
* [ ] Generated C header `generated/abi/hpm_crypto.h` (rolling deliverable
  from v0.1)
* [ ] First downstream consumer wired (AffineScript `stdlib/Crypto.affine`
  externs)
